# 雙店帳簿

諾奇意咖啡（Nose.Y Café）和拉亞漢堡新莊店的個人帳簿。手機和電腦都能用，可以加到主畫面。金額是新台幣整數，日期用台北時間。資料存在這台裝置的瀏覽器裡，不必登入，也不必有伺服器。

公開網站：[https://miketest1010.github.io/ledger/](https://miketest1010.github.io/ledger/)

打開時只有兩家店的名稱和分類，沒有收支紀錄。要把以前的帳帶回來，到 **設定 → 匯入檔案**，選擇以前匯出的 JSON 備份（格式 `shuangdian-ledger` 版本 1）。匯入會取代這台裝置上的資料。

## 在電腦打開

需要 Node.js 22。

```bash
npm install
npm run dev
```

瀏覽器打開 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

## 在手機打開

手機可以直接打開 [https://miketest1010.github.io/ledger/](https://miketest1010.github.io/ledger/)，再用瀏覽器把它加到主畫面。若要改程式、在自己的電腦上看，有兩種做法。

同一台電腦、同一個 Wi-Fi：

```bash
npm run dev -- --host
```

終端機會印出區網網址，例如 `http://192.168.1.20:43123`。手機瀏覽器打開那個網址。iPhone 用分享選單的「加入主畫面」。Android 用 Chrome 選單的「安裝應用程式」或「加到主畫面」。

給自己一個隨時能開的網址：先建置靜態檔，再放到任何靜態網站。

```bash
npm run build
npm run preview
```

`dist/` 就是整個網站，並且會多一份 `404.html`（和 `index.html` 相同），讓 GitHub Pages 能打開子路徑。正式站已經放在 [https://miketest1010.github.io/ledger/](https://miketest1010.github.io/ledger/)。網址必須是 `https://`，手機才比較容易安裝成主畫面 App。不要用檔案總管直接點 `index.html`，IndexedDB 和離線快取在 `file://` 下不會正常運作。

## 怎麼用

上方切換 **諾奇意咖啡**、**拉亞漢堡 新莊店**、**兩店合計**。

- **總覽**：本月和今年至今的收入、支出、淨額，月趨勢，分類，廠商。諾奇意另外有現金／Line Pay、其他收入、產品線、Line Pay 撥款，以及單月期的預估營業稅。拉亞另外有創業投入。2026 年 11 月以前的諾奇意支出會標「支出不完整，僅供參考」。
- **記一筆**：日期、店別、收入或支出或撥款、分類、金額、備註。收入可以拆現金和 Line Pay。帳務月份可以和付款日不同。可退押金、以前年度或一次性、產品線（例如寵物蛋糕）、保障期間都是選填。
- **紀錄**：搜尋、改、刪。
- **設定**：拉亞持股（預設空白）、分類、匯出 JSON／CSV、**匯入檔案**。這份公開版沒有預先寫入的帳，也不會重新載入起始資料。

Line Pay 撥款不算營收。補繳以前年度的稅可以從營業觀點排除。

## 備份

設定頁可以下載 JSON 或 CSV。JSON 含店別、分類、持股和全部紀錄，匯入會取代這台裝置上的資料。CSV 依編號更新或新增，不會刪掉檔案裡沒有的紀錄。CSV 用 UTF-8，並帶 BOM，Excel 開得了中文。

換手機或清掉瀏覽器資料之前，先匯出。
